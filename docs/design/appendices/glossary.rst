Glossary
********

.. glossary::

   build cache
      Disposable files under ``.build/`` created by compiles, runs, stress
      tests, and Codeforces data fetches.

   bundled source
      The single C++ file emitted by ``bundle`` for submission.

   case
      A numbered input/output pair under ``tests/<problem>/``.

   checked build
      A slower local build with stricter diagnostics and sanitizer support.

   problem identifier
      The local spelling for a Codeforces problem, such as ``A.71``.

   probe
      An ad hoc run against one input that is not yet part of the durable test
      set.
