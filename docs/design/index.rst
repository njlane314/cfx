cf-probs Design Outline

   \section*{Preface}

``cf-probs`` is a local Codeforces workspace for C++20 solutions, sample tests,
stress checks, cached reruns, and small command-line helpers.

This document is a Sphinx copy of the ``nobody`` documentation template, adapted
as a concise design outline for the ``cf-probs`` repository.
